How it works

The least invasive way to ship eval discipline

Gravel is a library, not a SaaS. It installs into your codebase, uses your database, and respects the auth you already have. Your domain experts get a polished dashboard; you keep your data.

Install in 5 minutes

One command. Browser-OAuth handshake. Framework detection for Next.js, Express, FastAPI, and Django. AST-aware edits with backup files on conflict — we never silently clobber.

Works in the codebases you already have. No restructure, no greenfield.

Runs in your infra

Traces, prompts, feedback, datasets — all in your own database. Your auth, your sessions, your domain. The only data that ever leaves is the rows you actively send to be judged.

Apache 2.0. Audit every line. No phone-home.

Free for the basics

Prompt management, GitHub PRs, tracing, feedback, datasets — all free, unlimited seats, forever. Pay only for the parts that need our judges: trace evals, live evals, unlimited static analysis.

Per-judge-call credits. Predictable spend.

Get started

One command. That's the whole install.

The wizard detects your framework, opens a browser to authenticate, AST-edits your server entry to mount the dashboard, runs migrations, and sends a test trace before exit.

# in your repo
$ npx @artanis/gravel init

Or for Python: python -m artanis_gravel init

In preview — ships with v0

The package isn't on npm yet. Star us on GitHub to get notified when v0 ships, or read the docs in the meantime.

The loop

Tracing → feedback → PR → eval. Repeat.

Your domain experts close the loop. Engineers stop being prompt-tweakers.

1

Auto-traced

OpenAI / Anthropic / Langchain / Vercel AI SDK calls land in your DB. Nothing to instrument.

2

DE labels

Domain experts thumbs-up/down outputs and write the correct version. That becomes ground truth.

3

Edit → PR

DE edits a prompt. "Submit" creates a real GitHub PR. Engineers review and merge as normal.

4

Eval gates regressions

Click "Run eval". Our judges score new outputs against the labels. Regressions surface in plain English.

Pair with Mallet

Mallet's prompt analyzer is built into Gravel

The same engine that powers our free standalone Mallet at artanis.ai/mallet ships inside Gravel's dashboard. As your domain experts edit prompts, Mallet flags contradictions, ambiguities, and best-practice gaps inline. Free tier: rate-limited. Paid tier: unlimited.
